ECSCW 2027 - website redesign mockup
Open index.html in any browser. All menu links work between pages.
Pages: index (Home), news, submissions, program (day tabs are clickable), attending, registration, venue, committees.
The menu follows the ECSCW 2026 structure: News, Submissions, Program, Attending, Committees.
Colours, font, logo, banner photo and chair photos come from the ECSCW 2027 announcement deck. Shared styles are in assets/site.css.
Text in [brackets] or marked TBA is placeholder content.
Fonts load from Google Fonts when online; offline it falls back to system fonts.
